# 炬森代理商销售分析 Skill

`jusen-distributor-sales-analysis` 用于把代理商导出的销售明细识别为炬森产品，并按客户生成可复核的销售汇总。它适用于不同 ERP、进销存或手工导出的 Excel 格式；工作表名称和表头不必与示例一致。

## 能解决什么问题

当销售明细中同时混有多个品牌、产品名称不规范、客户名称附带联系人或电话时，此 Skill 会：

- 从销售明细中筛出或识别炬森产品；
- 按内置的 2026 年产品三级分类，为产品匹配品类、细分品类和系列名；
- 将同一客户的销售额归并，并按销售额排序；
- 处理客户名称中的地区、店名、联系人、电话等信息；
- 根据业务员和销货日期计算客户的归属和回单次数；
- 保留产品匹配审计明细，让低置信度或待确认产品可以继续修正后再生成结果。

## 使用方式

将整个 `jusen-distributor-sales-analysis` 文件夹，按所用 Agent 支持的 Skill、插件或指令包方式加载。请确保 `SKILL.md` 与 `references/` 文件夹一起提供；本 Skill 会读取其中的产品分类表和人工修正规则。如果 Agent 不支持 Skill 文件夹，可在对话中提供 `SKILL.md`，并同时附上 `references/jusen-product-categories.md` 和 `references/manual-overrides.md`。

加载后，在同一个对话中提供销售明细文件，并说明希望生成炬森销售统计。例如：

```text
请使用 jusen-distributor-sales-analysis 分析这个 Excel 销售明细，
识别炬森产品并生成《炬森销售情况统计表》。
```

也可以直接补充你的业务口径，例如：

```text
不同地区的同名店不要合并；有多个业务员时按最后一次下单确定业务员；
请把无法可靠匹配的产品列为待确认。
```

分析开始时，Skill 会先查看工作簿的表头和少量样例，映射所需字段，而不是假定列名固定。若数据中已有品牌字段，建议指出炬森品牌的写法；若没有品牌字段，Skill 会通过产品名称和分类对照表识别，并说明可能存在的识别边界。

## 输入数据要求

Excel 中至少应包含以下三类信息（列名可不同）：

| 业务字段 | 是否必需 | 常见列名示例 |
| --- | --- | --- |
| 客户 | 必需 | 客户名称、往来单位、购货单位 |
| 产品 | 必需 | 产品名称、商品名称、存货名称、规格型号 |
| 金额 | 必需 | 销售额、含税金额、金额、出库金额 |
| 销货日期 | 建议提供 | 日期、单据日期、出库日期、销货日期 |
| 业务员 | 可选 | 业务员、销售员、经办人 |
| 销售数量 | 可选 | 数量、出库数量、销售数量 |
| 品牌/单据类型 | 可选 | 品牌、单据类型、业务类型 |

没有销货日期时无法按订单口径准确计算“回单次数”；没有业务员时，统计表仍可生成，但不会进行业务员归属拆分。

## 产品识别与人工修正

Skill 附带 2026 年炬森产品三级分类对照表，并依次采用标准化精确匹配、型号/规格匹配、铰链型号规则和相似度匹配。匹配会兼顾简称、同义词、录入差异和英寸/毫米换算，尽量让至少 95% 的源产品在文件 B 中找到候选标准名。铰链中 `DLH款`、`DL款`、`HQ2款`、`P款` 这类“1–3 个字母 + 可选 1 位数字 + 款”的型号会优先识别；“小飞鹰”按 `YH2款` 处理，“黑鲸”按 `DLH款` 处理。

95% 指“候选覆盖率”目标，不代表 95% 都已核实正确。产品匹配明细应提供前三个候选、匹配分数及依据；规格冲突、候选不唯一或置信度不足的仍标记为“待确认”，不参加自动汇总，也不丢弃其源金额。你可以在输出的 **产品匹配明细** 中写入正确的“备注（人工参考）”，再要求重新生成；可在分类对照表中找到的人工指定名称会优先采用。报告应分别说明候选覆盖率和已确认匹配率。

## 客户、业务员与订单口径

- 客户展示名优先保留“地区-店名”；没有店名时保留人名。
- 不同地区的同名店不合并。
- 有业务员时，原始客户名称完全相同但业务员不同的记录仍合并，业务员取最后一次下单对应的人；原始名称不同且业务员不同，即使清洗后的店名相同，也作为不同客户处理。
- 相同客户的销货日期相同，或与前一销货日期相差不超过两天，视为同一订单；间隔超过两天才增加一次回单。

## 生成结果

通常会生成一个 Excel 工作簿，至少包含以下工作表：

1. **炬森销售统计**：每行一个归并后的客户/业务员组合，包含：
   `客户名称`、`业务员`、`销售额`、`品类`、`品类数量`、`细分品类`、`细分品类数量`、`系列名`、`系列名数量`、`回单次数`。
2. **产品匹配明细**：保留源产品名称、已采用的匹配结果、前三个候选名称及分数、匹配依据、分类、置信度和人工备注，便于检查或修正。候选覆盖率与已确认匹配率分开显示。
3. **说明**：列出本次统计的筛选与计算口径。

“品类数量”“细分品类数量”“系列名数量”统计的是对应单元格中去重后的分类项数量，而不是产品件数。例如，品类为 `铰链；滑轨` 时，品类数量为 `2`。同一单元格内的分类会按该客户对应产品的销售数量降序排列；客户行则按销售额降序排列。

## 注意事项

- 先查看“产品匹配明细”中的待确认和低置信度记录，再把统计表用于经营决策。
- 退货、作废单、调拨单等是否排除，取决于原系统的单据业务含义；请在请求时明确口径。
- 产品对照表为 2026 年版本。出现新产品、停产产品或本地自定义名称时，建议在审计明细中做人工修正，并保留修正规则供下次复用。
